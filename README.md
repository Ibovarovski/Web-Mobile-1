## Capstone Project 1: Foundational Structure

### 🎯 Purpose
The initial goal was to build a multi-page personal website using semantic HTML5 tags. This phase focused purely on **content organization** and **structural integrity**.

### 🛠️ Key Achievements
* **Navigation:** Created a functional, linked navigation system across all pages.
* **Data Presentation:** Used the `<table>` element to present academic history and a weekly schedule.
* **User Input:** Implemented basic forms for contact information and a questionnaire, utilizing various input types (`text`, `email`, `radio`, `checkbox`, `select`, `textarea`).
* **Content:** Organized personal profile, skills, hobbies, and projects using headings and lists (`<ul>`, `<ol>`).

***

## Capstone Project 2: Styling and Modernization

### 🚀 Purpose
This phase modernized the website's look and feel by introducing CSS for styling and advanced layout techniques, ensuring the site is visually appealing and mobile-friendly.

### 🌟 Key Enhancements

1.  **Unified CSS Styling:**
    * Created and linked a central **`style.css`** for global consistency (fonts, background).
    * Applied custom CSS styling to tables, lists, and form elements.
    * Implemented a CSS **pseudo-class** (`:hover`) on the profile picture for an interactive effect.
2.  **Advanced Layouts & Responsiveness:**
    * **Weekly Schedule:** Used **CSS Flexbox** to manage the table layout container.
    * **Photo Gallery:** Created a new page utilizing **CSS Grid** for image arrangement.
    * **Media Queries:** Ensured the **Gallery** is responsive, switching from 3 columns (desktop) to 1 column (mobile).
3.  **Navigation and UX:**
    * Implemented a **sticky navigation bar** with distinct styling for the active page link, improving user experience.
4.  **Bootstrap Integration:**
    * The **Contact Me** page was redesigned using **Bootstrap 5 CDN**.
    * Utilized the **Bootstrap Grid System** (`row`, `col-lg-*`), **Form Components** (`form-control`), and **Utility Classes** (e.g., spacing and alignment).

### 🤔 Reflection on Bootstrap

* **Made Easier:** Rapidly creating a responsive, modern-looking form layout was trivial due to Bootstrap's built-in grid and utility classes, significantly cutting down on manual CSS for alignment and spacing.
* **More Restrictive:** Achieving subtle deviations from Bootstrap's default design required writing more specific custom CSS rules to override the framework, which can sometimes be less intuitive than starting from scratch.
